# 001 — Контракты

Тип: подготовка

Основание: все FR и NFR (форма данных, ошибки, события) ([Dev Spec](../spec.md))

Зависимости: нет

Половины: tasks-core + notify-service + frontend, ревьюят все стороны вместе

Результат: контракты комментариев и события об упоминании лежат у владельцев, стороны работают независимо

Почему отдельно: —

## Контракты
- tasks-core: контракт комментариев — МЕНЯЕТ КОНТРАКТ: создание, правка, удаление, список
- tasks-core: событие об упоминании — МЕНЯЕТ КОНТРАКТ: новое событие для notify-service
