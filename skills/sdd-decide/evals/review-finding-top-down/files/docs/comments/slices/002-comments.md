# 002 — Комментарии в задаче

Тип: поведение

Основание: FR-1, FR-2, FR-3, FR-4, FR-5, FR-6, FR-7, NFR-1, NFR-2

Зависимости: 001

Половины: tasks-core + frontend, принимаются вместе

Результат: участники обсуждают задачу в карточке и упоминают коллег

Почему отдельно: —

## Общая приёмка (собранное приложение)
```
AC-002-1 Обсуждение в карточке [FR-1, FR-3]
  WHEN Анна в 10:00 и Борис в 10:05 оставили комментарии в TASK-42
  THEN Вера видит в карточке TASK-42 сначала комментарий Анны, потом Бориса
```

## Tasks-core-половина
```
AC-002-B1 Кто комментирует [FR-1]
  WHEN Дина отправляет комментарий к TASK-42
  THEN отказ «Нет доступа к задаче», комментарий не сохранён
```

```
AC-002-B2 Длина текста [FR-2]
  WHEN Борис отправляет комментарий из 5001 символа
  THEN отказ «Комментарий длиннее 5000 символов»
  WHEN Борис отправляет 5000 символов
  THEN комментарий сохранён
```

```
AC-002-B3 Правка через 15 минут [FR-4]
  WHEN Борис правит свой комментарий через 16 минут
  THEN отказ «Время на изменение истекло», текст прежний
```

```
AC-002-B4 Удаление чужого [FR-5]
  WHEN Анна удаляет комментарий Бориса
  THEN отказ «Удалить может автор или руководитель проекта»
```

```
AC-002-B5 Кого можно упомянуть [FR-6, FR-7]
  WHEN Анна запрашивает подсказки по «@Гле»
  THEN подсказок нет
```

```
AC-002-B6 Скорость [NFR-1, NFR-2]
  WHEN в TASK-42 2000 комментариев
  THEN p95 публикации ≤ 300 мс
   AND p95 подсказок упоминаний ≤ 200 мс в проекте до 500 участников
```

## Frontend-половина
```
AC-002-F1 Правка и пометка [FR-4]
  WHEN Борис правит свой комментарий через 10 минут
  THEN Вера видит у комментария пометку «изменён»
```

```
AC-002-F2 Удалённый комментарий [FR-5]
  WHEN Вера удалила комментарий Бориса
  THEN на его месте «Комментарий удалён»
```

```
AC-002-F3 Подсказки упоминаний [FR-6]
  WHEN Анна вводит «@Бо»
  THEN в подсказке «Борис Иванов, разработчик»
  WHEN Анна вводит «@Б»
  THEN подсказок нет
```

## Границы
- Вне slice: уведомления об упоминаниях (003).
- Пересечения с соседями: нет.
