# Проверка: требования

Скрипт уже проверил: каждая строка протокола указана в «Из протокола:», у каждого FR есть источник,
«Пример:» с персонажем, числа в NFR из протокола, пары границ, числа из рекомендаций агента,
стоп-слова, открытые вопросы, объём, ссылки на код. Это не перепроверяй — бери из вывода lint.

1. **Смысл трассировки.** Строка протокола и FR, под которым она стоит в «Из протокола:», говорят
   об одном. Пары решение → FR показывает `<скрипт> trace docs/<feature>`.
   Решение не искажено: исключения, тексты, условия перенесены целиком. Искажение — блокер.
2. **Нет выдуманного.** В FR нет условий и исключений, которых нет в решении его строки протокола.
   Правило без решения — блокер, его место в «Открытые вопросы».
3. **Оба исхода.** У правил «можно / нельзя» есть пример и для «можно», и для «нельзя».
4. **Слова пользователя.** Нет внутренностей, которых lint не ловит: внутренних статусов, названий
   сервисов, имён классов по-русски. Тексты сообщений — в «ёлочках».
5. **Пустое и пробелы.** Для каждого ввода решено, что с пустым значением и с пробелами.
6. **Краевые ситуации.** Повтор действия, два действия одновременно, недоступность источника
   данных, несколько вкладок и устройств — у каждой ситуации есть FR или «не входит в задачу».
7. **Противоречия.** Одна ситуация не получает два разных исхода в разных FR.
8. **NFR.** Условие объёма осмысленное: на таком объёме задачу действительно будут использовать.

## Связанное поведение и обеспечение

Проверяй цель пользователя, применимые развилки пути, согласованность FR/SC/tech/ADR/AC
и подтверждённость существенных технических предпосылок. Полный чеклист не означает
обязательный вопрос по каждой неприменимой теме. На простой фиче достаточно короткого пути
и применения существующего механизма; отсутствие сложной архитектуры не является находкой.
При повторном ревью начни с изменившейся области и её связей через trace; неизменённые
проверенные материалы не перечитывай без конкретной причины. Если область неизвестна,
явно расширь её. Структурные связи не доказывают смысловую полноту и не заменяют ревью.
Находка, требующая решения, связывается с Q через существующий triage; механическую
ошибку исправляет инструмент, не превращай её в интервью. Само ревью не закрывает Q
и не согласует документы.
