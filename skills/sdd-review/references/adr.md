# Чеклист: ADR

Скрипт уже проверил: разделы, не меньше двух вариантов, вердикт у каждого и один выбранный,
ссылки отклонённых на FR/NFR, ID в «Контексте», номера slices в шапке и «Последствия»,
пометку «блокирует» в «Не выяснено». Это не перепроверяй.

1. **Нужен ли.** Выполнены три условия: дорого откатить, удивит без контекста, был реальный выбор.
2. **Отклонение честное.** Отклонённый вариант правда не выполняет названное требование.
3. **Проверяемость.** Каждое правило «Решения» можно проверить тестом или ревью кода.
4. **Правила для сервисов.** В «Последствия» выписаны правила для AGENTS.md затронутых сервисов.
5. **Поведение.** ADR не вводит поведения, которого нет в Dev Spec; если вводит — блокер,
   решение идёт через `/sdd-decide`.
