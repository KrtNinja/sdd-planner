# Чеклист: ADR

1. **Нужен ли.** Выполнены три условия: дорого откатить, удивит без контекста, был реальный выбор.
2. **Требования.** «Контекст» перечисляет FR/NFR, которые решение обязано выполнить, с ID.
3. **Варианты.** Не меньше двух. Отклонённые отклонены через требование («не выполняет NFR-3»),
   а не через вкус.
4. **Проверяемость.** Каждое правило «Решения» можно проверить тестом или ревью кода.
5. **Последствия.** Названы затронутые slices по номерам и что в них меняется; правила для
   AGENTS.md сервисов выписаны.
6. **Поведение.** ADR не вводит поведения, которого нет в Dev Spec; если вводит — блокер,
   решение идёт через `/sdd-decide`.
7. **Не выяснено.** У каждого пункта сказано, блокирует ли он slices.
