# Чеклист: ADR

Скрипт уже проверил: разделы, не меньше двух вариантов, вердикт у каждого и один выбранный,
ссылки отклонённых на FR/NFR или ОГР-n, описание каждого ОГР-n в «Контексте», ID в «Контексте»,
номера slices в шапке и «Последствия», пометку «блокирует» в «Не выяснено», ссылки на код (пути,
файлы, вызовы, внутренние имена). Это не перепроверяй.

1. **Нужен ли.** Выполнены три условия: дорого откатить, удивит без контекста, был реальный выбор.
2. **Отклонение честное.** Отклонённый вариант правда не выполняет названное требование или правда
   нарушает названное ограничение.
3. **Ограничение настоящее.** У каждого ОГР-n назван источник, и это решение вне фичи: компании,
   бюджета, ресурсов, сроков. Предпочтение автора ADR, выданное за ограничение, — блокер.
4. **Цена названа.** В «Последствия» сказано, чем платим за выбор.
5. **Без соглашений о коде.** В ADR нет правил для кода сервисов: слоёв, способов обработки событий,
   устройства модулей. Их место — репозиторий сервиса, в зоне реализации.
6. **Поведение.** ADR не вводит поведения, которого нет в Dev Spec; если вводит (в том числе через
   «Чем платим») — блокер, решение идёт через `/sdd-decide`.
