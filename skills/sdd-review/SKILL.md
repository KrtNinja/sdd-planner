# sdd-review — ревью перед одобрением

Скрипт lint: `node scripts/sdd-lint.mjs`, дальше — `<скрипт>`. Запускай из корня репозитория с доками.

Вход: фича и режим: `spec`, `slices` или `adr` (для adr — номер или «все ADR фичи»).
Выход: `docs/<feature>/review/<spec | slices | adr-NNNN>.md` — таблица находок с ID `R1`, `R2` …;
та же таблица в ответе. Артефакты (протокол, spec, slices, ADR) не меняются.

Ревью идёт в новой сессии, чтобы агент не проверял то, что сам только что написал по памяти.
Правки вносит человек или `/sdd-decide`, поэтому здесь только находки. Файл нужен, чтобы
находки пережили сессию: `/sdd-decide <feature> R2 …` берёт вопрос из него, а одобрение
не пройдёт, пока у блокера пустое «Решение».
Механику проверил скрипт. Ты проверяешь только смысл — то, чего скрипт не видит.

## Шаги

1. Запусти `node <папка этого скилла>/../sdd-lint/scripts/sdd-lint.mjs docs/<feature>`. Перенеси его находки в таблицу шага 4 как есть:
   ОШИБКА — «блокер», ВНИМАНИЕ — «замечание», в «Пункт» — ID правила (`SL-16`).
   Сам эти вещи не перепроверяй. Находки `RV-*` — о прошлом ревью, их не переноси.
2. Открой чеклист режима:
   - `spec` → [references/spec.md](references/spec.md)
   - `slices` → [references/slices.md](references/slices.md)
   - `adr` → [references/adr.md](references/adr.md)
3. Пройди все пункты чеклиста по порядку. Для каждого прочитай нужные файлы целиком.
   Выведи строку пунктов с отметками, например: `1 ок · 2 ок · 3 две находки · 4 ок`.
4. Запиши находки в `docs/<feature>/review/<режим>.md` по [assets/review.md](assets/review.md);
   для adr — файл на каждый ADR, `review/adr-NNNN.md`. Файл прошлого ревью этого режима
   перезапиши целиком: открытые находки ты нашёл заново, закрытые уже не нужны.
   - `#` — `R1`, `R2` … по порядку;
   - важность: «блокер» — нельзя одобрять, «замечание» — можно одобрить и поправить позже;
   - «Где» — файл и ID (`slices/003-transfer.md, AC-003-B6`);
   - «Предложение» — конкретный вариант: решение для `/sdd-decide` или правка файла;
   - «Решение» оставь пустым — его заполняют после ревью.
   Нет находок — файл всё равно пиши, с итогом «блокеров 0, замечаний 0» и пустой таблицей.
5. Выведи таблицу и итог: «Блокеров: N, замечаний: M, файл: docs/<feature>/review/<режим>.md.
   Решение по находке — `/sdd-decide <feature> R<n> "<решение>"` или «да», чтобы принять предложение;
   правка — исправьте файл и впишите «исправлено» в «Решение».» Остановись.
