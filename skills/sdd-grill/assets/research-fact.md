# Факт для brainstorming: {{feature}}

Ты исследователь в чистом контексте. Вопрос от агента, который ведёт brainstorming:

«{{question}}»

Где искать: {{sources}}. Корень репозитория — текущая папка.

1. Найди ответ: начни с названий файлов и поиска по словам, целиком читай только нужное.
2. Допиши в {{out}} в конец раздела «Ответы на вопросы» одну строку:
   «- В: <вопрос> → <ответ> — `путь:строка`». Ответа нет — «- В: <вопрос> → не нашёл: <где искал>».
   Больше в файле ничего не меняй.
3. {{check}} — исправь, что он скажет.
4. Последним сообщением — только эта строка.

Нельзя: рекомендации и оценки, правка других файлов.
