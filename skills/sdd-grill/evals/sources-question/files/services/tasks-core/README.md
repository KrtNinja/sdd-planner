# tasks-core

Сервис задач: проекты, задачи, участники.

- Роли в проекте: руководитель проекта, участник, наблюдатель (только чтение).
- У задачи ровно один исполнитель — поле `assignee_id`; исполнителем может быть только участник проекта.
- Каждое изменение задачи публикуется событием `task.updated`; его читают audit и notify-service.
- Заблокированный сотрудник остаётся в проекте, но войти и получать уведомления не может.
