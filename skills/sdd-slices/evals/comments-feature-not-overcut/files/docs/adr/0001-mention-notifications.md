# ADR-0001: Доставка уведомлений об упоминаниях через брокер

Статус: предложено

Фича: [Комментарии с упоминаниями](../comments/spec.md)

Затрагивает slices: появятся после нарезки

## Контекст
FR-10 и NFR-3: уведомление не теряется, не дублируется, сбой доставки не мешает публикации.
Сервисы: frontend, tasks-core (комментарии), notify-service (колокольчик, новый потребитель).

## Варианты

### A. Синхронный вызов notify-service
- минус: сбой notify-service роняет публикацию (FR-10)

Отклонён: не выполняет FR-10.

### B. Outbox в tasks-core и брокер
- плюс: событие не теряется после коммита; notify-service идемпотентен

Выбран.

## Решение
Outbox в tasks-core, событие об упоминании в брокер, notify-service идемпотентен по паре
(комментарий, упомянутый). Брокер для notify-service ещё не подключён — нужна настройка
инфраструктуры командой платформы.

## Последствия
- Уведомления об упоминаниях ждут подключения notify-service к брокеру.

## Не выяснено
- Срок подключения notify-service к брокеру — блокирует уведомления об упоминаниях.
