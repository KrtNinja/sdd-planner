# ADR-0001: Доставка уведомлений об упоминаниях через брокер

Статус: предложено
Фича: [Комментарии с упоминаниями](../comments/spec.md)

## Контекст
FR-10 и NFR-3: уведомление не теряется, не дублируется, сбой доставки не мешает публикации.
Сервисы: frontend, tasks-core (комментарии), notify-service (колокольчик, новый потребитель).

## Решение
Outbox в tasks-core, событие `comment.mentioned` в брокер, notify-service идемпотентен по
(комментарий, упомянутый). Брокер для notify-service ещё не подключён — нужна настройка
инфраструктуры командой платформы.

## Не выяснено
- Срок подключения notify-service к брокеру.
