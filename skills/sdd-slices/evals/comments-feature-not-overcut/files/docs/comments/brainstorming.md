# Комментарии с упоминаниями — Brainstorming

Статус: готов
Запрос: «Добавьте комментарии в задачи, чтобы можно было звать коллег через @»
Сервисы: frontend, tasks-core, notify-service

## Решения

| # | Ветка | Вопрос | Рекомендация агента | Решение |
|---|---|---|---|---|
| 1 | Продукт и UI | Кто комментирует | Любой участник проекта | Любой, кто видит задачу |
| 2 | Продукт и UI | Лимит длины | 2000 символов | 5000 символов, пробелы-only нельзя |
| 3 | Продукт и UI | Порядок | Новые сверху | Старые сверху |
| 4 | Продукт и UI | Редактирование | Всегда | 15 минут, пометка «изменён» |
| 5 | Продукт и UI | Удаление | Только автор | Автор и руководитель, остаётся «Комментарий удалён» |
| 6 | Продукт и UI | Подсказки @ | С 1 символа, 20 штук | С 2 символов, до 10, по алфавиту |
| 7 | Продукт и UI | Кого можно упомянуть | Любого в организации | Только тех, кто видит задачу |
| 8 | Стыки сервисов | Уведомление | Синхронно из tasks-core | Асинхронно через notify-service, сбой не мешает публикации |
| 9 | Стыки сервисов | Повтор при редактировании | Уведомить снова | Только новых упомянутых |
| 10 | Сервер | NFR | — | Публикация 300 мс, подсказки 200 мс, уведомление 2 с |

## Вне scope
- Вложения, форматирование, реакции, ветки, email/push, realtime чужих комментариев.
