# Экспорт задач в CSV — Brainstorming

Статус: готов

Запрос: «Хочу выгружать список задач в CSV»

Сервисы: frontend, tasks-core

## Решения

| # | Ветка | Вопрос | Рекомендация агента | Решение |
|---|---|---|---|---|
| 1 | Продукт и UI | Кто выгружает | Любой участник проекта | Руководитель проекта и администраторы организации |
| 2 | Продукт и UI | Что попадает в файл | Все задачи проекта | Ровно то, что сейчас в списке с учётом фильтров |
| 3 | Продукт и UI | Колонки | Все поля задачи | Номер, название, статус, исполнитель, срок |
| 4 | Продукт и UI | Где кнопка | В меню проекта | Кнопка «Экспорт» над списком задач |
| 5 | Продукт и UI | Имя файла | export.csv | `<проект>-задачи-<дата>.csv` |
| 6 | Продукт и UI | Пустой список | Пустой файл | Кнопка неактивна, подсказка «Нет задач для выгрузки» |
| 7 | Сервер | Лимит строк | 10 000 | Нужен, 10 000 задач; больше — просим уточнить фильтр |
| 8 | Сервер | Как генерировать большой файл | Синхронно | Асинхронно через очередь RabbitMQ, файл в S3, ссылка приходит в колокольчик |
| 9 | Сервер | Кодировка | UTF-8 | UTF-8 с BOM, чтобы Excel открывал кириллицу |
| 10 | Сервер | NFR | — | Файл готов за p95 ≤ 30 с для 10 000 задач |

## Вне scope
- Экспорт в Excel и PDF.
- Выбор колонок пользователем.
- Выгрузка по расписанию.

## Где агент угадал бы не так

| # | Рекомендация агента | Решение человека | Чем плоха догадка |
|---|---|---|---|
| 1 | Любой участник проекта | Руководитель проекта и администраторы организации | Выгрузка всех задач любым участником |
| 2 | Все задачи проекта | Ровно то, что сейчас в списке с учётом фильтров | Файл не совпадал бы с экраном |
| 3 | Все поля задачи | Номер, название, статус, исполнитель, срок | Лишние поля и персональные данные в файле |
| 4 | В меню проекта | Кнопка «Экспорт» над списком задач | Кнопку не нашли бы рядом со списком |
| 5 | export.csv | `<проект>-задачи-<дата>.csv` | Файлы разных проектов не различить |
| 6 | Пустой файл | Кнопка неактивна, подсказка «Нет задач для выгрузки» | Пустой файл выглядит как ошибка |
| 7 | 10 000 | Нужен, 10 000 задач; больше — просим уточнить фильтр | Без поведения при превышении |
| 8 | Синхронно | Асинхронно через очередь RabbitMQ, файл в S3, ссылка приходит в колокольчик | Большая выгрузка висела бы в браузере |
| 9 | UTF-8 | UTF-8 с BOM, чтобы Excel открывал кириллицу | Excel показывал бы кракозябры |
