# Экспорт задач в CSV — Dev Spec

Статус: одобрено 27.10.2026

Протокол: [brainstorming.md](brainstorming.md)

## Цель

- **Что сможет пользователь:** руководитель выгружает текущий список задач в файл, чтобы
  отчитаться или обработать его в таблице.
- **Как было до фичи:** список можно было только смотреть на экране.

## Функциональные требования

```
FR-1  Выгрузить список может руководитель проекта и администратор организации.
      Остальные кнопки «Экспорт» не видят; запрос → «Выгрузка доступна руководителю».
      Пример: Вера и Олег видят «Экспорт», Анна — нет.
```

```
FR-2  В файл попадают ровно задачи текущего списка с учётом фильтров, в том же порядке.
      Пример: Вера ставит фильтр «В работе» → в файле только TASK-42.
```

```
FR-3  Колонки: номер, название, статус, исполнитель, срок. Пустой срок — пустая ячейка.
      Кириллица открывается в Excel без ручной настройки.
      Пример: строка TASK-51 «Экран оплаты» — срок пустой, название читается в Excel.
```

```
FR-4  Кнопка «Экспорт» стоит над списком задач. Имя файла: «<проект>-задачи-<дата>.csv».
      Пример: Вера выгружает 27.10.2026 → «Мобильное приложение-задачи-27.10.2026.csv».
```

```
FR-5  Если в списке нет задач, кнопка «Экспорт» неактивна с подсказкой «Нет задач для выгрузки».
      Пример: Вера ставит фильтр «На паузе», задач нет → кнопка неактивна.
```

```
FR-6  Выгрузка больше 10 000 задач не выполняется: «Слишком много задач, уточните фильтр».
      Пример: в списке Веры 10 000 задач — файл готовится, 10 001 — отказ.
```

```
FR-7  Файл готовится в фоне, ссылка на него приходит Вере в колокольчик.
      Пример: Вера нажала «Экспорт» и ушла в другую задачу → через время в колокольчике ссылка на файл.
```

## Нефункциональные требования

```
NFR-1 Файл на 10 000 задач готов: p95 ≤ 30 с.
```

## Вне scope
- Excel и PDF, выбор колонок, выгрузка по расписанию.
