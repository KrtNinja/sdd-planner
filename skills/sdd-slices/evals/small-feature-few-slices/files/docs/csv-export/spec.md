# Экспорт задач в CSV — Dev Spec

Статус: одобрено 27.10.2026 (checkpoint 1)
Протокол: [brainstorming.md](brainstorming.md)

## Цель
Руководитель выгружает текущий список задач в файл, чтобы отчитаться или обработать его
в таблице. До фичи список можно было только смотреть на экране.

## Данные для примеров
- Вера Смирнова, руководитель проекта «Мобильное приложение»
- Олег Ким, администратор организации
- Анна Петрова, разработчик

В проекте 3 задачи: TASK-42 «Починить вход по SMS» (В работе, Анна, 30.10.2026),
TASK-50 «Обновить иконки» (Закрыта, Борис, 20.10.2026), TASK-51 «Экран оплаты» (Отменена, Анна, —).

## Функциональные требования

```
FR-1  Выгрузить список может руководитель проекта и администратор организации.
      Остальные кнопки «Экспорт» не видят; запрос → «Выгрузка доступна руководителю».
      Пример: Вера видит «Экспорт», Анна — нет.
```

```
FR-2  В файл попадают ровно задачи текущего списка с учётом фильтров, в том же порядке.
      Пример: фильтр «В работе» → в файле только TASK-42.
```

```
FR-3  Колонки: номер, название, статус, исполнитель, срок. Пустой срок — пустая ячейка.
      Кириллица открывается в Excel без ручной настройки.
```

```
FR-4  Имя файла: «<проект>-задачи-<дата>.csv».
      Пример: «Мобильное приложение-задачи-27.10.2026.csv».
```

```
FR-5  Если в списке нет задач, кнопка «Экспорт» неактивна с подсказкой «Нет задач для выгрузки».
```

```
FR-6  Выгрузка больше 10 000 задач не выполняется: «Слишком много задач, уточните фильтр».
```

## Нефункциональные требования

```
NFR-1 Файл на 10 000 задач скачивается: p95 ≤ 5 с.
```

## Вне scope
- Excel и PDF, выбор колонок, выгрузка по расписанию.
